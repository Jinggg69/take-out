# 均州鱼庄管理系统

## Platform

web，桌面端餐饮门店运营后台，中文界面。

## Product purpose

在保留苍穹外卖管理端业务功能、接口和操作流程的基础上，升级 Vue3 并采用均州鱼庄品牌。
使用者处理门店订单、菜品、套餐、分类、员工及经营统计。

## Constraints

- 原参考项目位于同级源码归档内，不修改或覆盖。
- 不修改 Spring Boot 后端、数据库、API、Token 协议、业务规则。
- 不增加多租户、RBAC、堂食等业务。
- 阶段 B 已接入登录退出、认证与偏好 Store、七项导航、营业状态、修改密码及订单提醒。
- 阶段 C 已迁移员工列表、姓名搜索、分页、启停、新增、修改和保存并继续添加，保留原字段、接口、校验及admin行保护。
- 阶段 D 已迁移分类名称/类型查询、分页、菜品/套餐分类新增、修改、启停、删除及保存并继续添加，关联删除限制仍由后端处理。
- 七个业务菜单及三个新增/编辑路由均保留；员工及分类页面已开放，其余五个业务模块按后续阶段逐项迁移。
- 不展示模拟经营数据；订单提醒仍携带原 orderId 参数，订单详情在阶段 G 接入。
- `inform` 与旧 `chart` 页面有源码但未注册路由，不在迁移时擅自启用或删除。
