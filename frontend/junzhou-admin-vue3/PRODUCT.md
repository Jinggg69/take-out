# 均州鱼庄管理系统

## Platform

web，桌面端餐饮门店运营后台，中文界面。

## Product purpose

基于 Vue 3 构建均州鱼庄门店运营后台，兼容现有后端接口与业务规则。
使用者处理门店订单、菜品、套餐、分类、员工及经营统计。

## Constraints

- 原参考项目位于同级源码归档内，不修改或覆盖。
- 原前端迁移阶段不修改 Spring Boot 后端、数据库、API、Token 协议、业务规则。2026-10-26 后续认证修复已授权配套后端持久会话与增量建表；改密成功后清除前端认证并转到登录页，路径和请求头保持兼容。
- 不增加多租户、RBAC、堂食等业务。
- 阶段 B 已接入登录退出、认证与偏好 Store、七项导航、营业状态、修改密码及订单提醒。
- 阶段 C 已迁移员工列表、姓名搜索、分页、启停、新增、修改和保存并继续添加，保留原字段、接口、校验及admin行保护。
- 阶段 D 已迁移分类名称/类型查询、分页、菜品/套餐分类新增、修改、启停、删除及保存并继续添加，关联删除限制仍由后端处理。
- 阶段 E 已迁移菜品三项筛选、分页、多选与批量删除、行删除/启售/停售、新增/修改、预设口味、图片上传及保存并继续添加，保留元价格、口味序列化及后端删除限制。
