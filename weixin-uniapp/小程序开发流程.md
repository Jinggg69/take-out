# 均州鱼庄小程序开发流程

## 导入与运行

1. 使用 HBuilderX 导入 `weixin-uniapp` 目录，沿用现有 Vue 2 uni-app 工程。
2. 核对 `manifest.json` 的微信小程序 AppID；若使用根目录的 `project.config.json`，同步核对其中的 AppID。使用自己具备权限的应用配置。
3. 在 `utils/env.js` 中设置后端地址。默认 `http://localhost:8080` 用于本机开发；真机联调需使用设备可访问的地址。
4. 在微信开发者工具中开启服务端口，在 HBuilderX 中配置开发者工具路径。
5. 通过 HBuilderX“运行 → 运行到小程序模拟器 → 微信开发者工具”编译运行；真机预览前核对设备访问与域名配置。

当前仓库的 `package.json` 只声明组件依赖，没有独立的 npm 构建命令。编译产物位于 `unpackage/`，不纳入版本管理。

## 目录说明

| 入口 | 用途 |
| --- | --- |
| `pages.json` | 页面注册、导航栏及全局样式配置 |
| `manifest.json` | 应用名称、平台配置及权限说明 |
| `App.vue`、`main.js` | 应用入口与全局样式 |
| `pages/` | 菜单、地址、结算、支付、订单等页面 |
| `pages/api/api.js` | 业务接口封装 |
| `utils/env.js`、`utils/request.js` | 后端地址与请求封装 |
| `store/` | 用户、购物车等客户端状态 |
| `static/`、`components/` | 静态资源与业务组件 |
| `tests/` | Node 回归测试 |

## 联调检查

- 先按根目录 README 启动后端及依赖，并按 `database/migrations/README.md` 完成所需数据库迁移。
- 验证登录、菜单与套餐加载、规格选择、购物车增减、地址新增和编辑、结算报价与订单查询。
- 结算依赖 `GET /user/order/quote`；报价失败应阻止下单，金额变化后应由用户重新确认。
- 核对商户信息等页面依赖的接口是否由当前后端提供；保留的桌台字段不能作为堂食功能已完成的依据。
- 支付与退款需配套微信商户及通知配置，在实际环境验证；本地回归通过不能替代支付验收。

## 本地回归

在小程序目录执行：

```powershell
node --test tests/*.test.cjs
```

发布前还需通过微信开发者工具和真机检查接口连通、授权、页面跳转、支付及异常提示。功能与结算规则见 [小程序说明](README.md)，项目来源见根目录 README。
