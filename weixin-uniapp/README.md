# 均州鱼庄点餐小程序

基于 Vue 2、uni-app 和 Vuex 的用户端，与现有 Java 后端配套。当前以单店外卖为业务基础，包含菜单、菜品规格、购物车、收货地址、结算、支付和订单查询页面。

桌台相关字段及接口定义不代表已实现堂食或多门店；商户信息接口、微信登录、支付与真机运行情况需结合实际后端联调确认。项目来源见根目录 README。

## 本地开发

使用 HBuilderX 导入本目录，配置小程序 AppID，并通过“运行到小程序模拟器 → 微信开发者工具”启动。配置步骤与联调检查见 [小程序开发流程](小程序开发流程.md)。

接口地址配置在 `utils/env.js`，当前为 `http://localhost:8080`；真机联调需替换为设备可访问的后端地址。发布前核对实际服务地址及小程序域名配置。

## 结算接口

结算页使用 `GET /user/order/quote` 获取后端报价，请求头沿用 `authentication`。后端按当前商品价格计算商品小计、每购买份数 1 元打包费和每单 6 元配送费，并校验商品及套餐组成可售。

进入结算页后使用后端报价更新商品和费用；报价失败时不能使用旧报价下单。提交使用 `POST /user/order/submit`，`amount` 是用户确认金额，后端再次重算；金额变化时刷新报价供用户再次确认，不自动重提。

提交请求携带 `clientRequestId`；遇到不确定失败时保留原请求内容与请求号，供用户显式重试。订单详情支持展示退款状态。

先发布支持报价与当前订单生命周期的后端，再发布本小程序。已有数据库升级步骤见 [数据库迁移说明](../database/migrations/README.md)。

```powershell
node --test tests/*.test.cjs
```

现有测试覆盖地址保存、购物车口味、结算报价、请求重试、退款展示及时间处理。Node 回归不能替代微信开发者工具、真实后端与真机验收。
